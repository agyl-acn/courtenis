# Runtime-only dependencies for the AWS Lambda deployment package.
#
# BUILD THIS ON LINUX (AWS CloudShell / Amazon Linux) — see build_lambda_linux.sh.
# Building on Windows fails: mcp declares `pywin32; sys_platform == "win32"`, and
# pip's --platform flag does not override marker evaluation, so a Windows host
# demands pywin32 (no Linux wheel). On Linux the marker is false and pip resolves
# the full tree cleanly with native wheels.
#
# Two deliberate differences from requirements.txt:
#   1. NO uvicorn — Mangum (lambda_handler.py) is the ASGI adapter on Lambda.
#   2. NO boto3/botocore — the Lambda Python 3.12 runtime ships these preinstalled;
#      bundling them adds ~35 MB. (build_lambda_linux.sh also strips them as a
#      safety net in case a transitive dep pulls them in.)
#
# Versions pinned to the local venv set so Lambda behaves identically to local.
